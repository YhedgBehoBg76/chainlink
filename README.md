# High-Performance Chain-Link Mesh Simulation Pipeline

This project contains the Python Machine Learning and Visualization pipeline for the High-Performance Chain-Link Mesh Simulation. It trains LightGBM surrogate models to predict ultimate tension (T_ult), maximum absorbed energy (E_abs_max), and rupture probability. It then uses inverse design to evaluate candidates and identify the Pareto frontier. Visualization tools are included to compare stress/strain and render 3D impacts using PyVista.

## Requirements
Ensure you have the required Python packages installed:
```bash
pip install pandas numpy lightgbm shap joblib matplotlib scikit-learn pyvista
```

## Launch Instructions

The pipeline can process data generated by the C++ core or fall back to mock data if it does not exist yet. Run the scripts from the project root in the following order:

### 1. Train the LightGBM Surrogate
Train the LightGBM models (Regression and Classification) using 5-fold CV and generate SHAP summary plots.
```bash
python ml_pipeline/train_lightgbm_surrogate.py
```
*Outputs: trained models in `ml_pipeline/models/` and SHAP plots in `visualization/plots/`.*

### 2. Run Inverse Design and Pareto Frontier
Evaluate 100,000+ candidates using the trained surrogate and find the Pareto frontier (min Areal Mass vs max T_ult).
```bash
python ml_pipeline/inverse_design_pareto.py
```
*Outputs: Pareto plot at `visualization/plots/04_lightgbm_shap_and_pareto.png`.*

### 3. Generate Stress-Strain Comparative Plots
Generate tension/compression graphs comparing different mesh configurations.
```bash
python visualization/plot_stress_strain.py
```
*Outputs: Stress/strain plot at `visualization/plots/01_comparative_tension_compression.png`.*

### 4. Render 3D Impacts with PyVista
Render 3D impact scenarios off-screen.
```bash
python visualization/render_3d_impact_pyvista.py
```
*Outputs: 2D image at `visualization/plots/02_3d_impact_pyvista.png` and interactive HTML at `visualization/plots/03_interactive_3d_impact.html`.*
